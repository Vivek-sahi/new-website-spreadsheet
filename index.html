How it works

From live grid to shared answer in three steps

Open a live model as a grid, work in it, then save or publish the analysis.

Open any model as a grid

Work on any semantic model in a spreadsheet interface, queried live from your warehouse. Sort, filter, and apply conditional formatting in the grid.

Work with formulas and inputs

Use 70+ native formulas, add input tables or new columns for forecasts and notes, and watch results update as you go.

Save, share or write back

Save the sheet as an Answer, a shared view your team can search, open, and edit. Publish inputs to the warehouse with Writeback, ready for Spotter and Liveboards.
